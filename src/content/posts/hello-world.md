This is the first post on my rebuilt personal website. I wanted a place to write about things I'm working on, learning, or thinking about — without needing an account on someone else's platform.

## Why this setup

The site is a static export built with Next.js. Blog posts are plain markdown files that live right in the repo, so publishing is just writing a file and deploying. No database, no CMS, nothing to maintain.

## What's next

I'll be using this space for write-ups on projects, homelab/self-hosting notes, and whatever else seems worth documenting. If you're reading this — welcome.
